Security Architecture

🪖
Helmet.js
HTTP security headers (CSP, HSTS, X-Frame-Options) on every Express response
🔒
JWT + Refresh Token Rotation
Short-lived access tokens (15m) + long-lived refresh with automatic rotation on use
🚦
Rate Limiting
express-rate-limit on auth routes (5 req/min), Redis-backed window for API routes
🛡️
RBAC Permissions
Roles: buyer, agent, admin, super-admin. Middleware guards on every protected route
🧹
Input Sanitization
express-mongo-sanitize, xss-clean, DOMPurify on client. Zod schema validation on all inputs
🖼️
Cloudinary Signed Uploads
Server-side signed upload presets. No direct client-to-Cloudinary writes. File type + size validation
🔑
CSRF Protection
Double-submit cookie pattern on all state-mutating requests. SameSite=Strict cookies
📊
Sentry + Audit Logs
Error tracking, performance monitoring, admin action audit trail stored in DB
